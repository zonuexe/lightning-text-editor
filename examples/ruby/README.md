# inzm - Ruby (Pure Ruby & 自己拡張型 Emacs) 実装サンプル

外部gem一切不要（Pure Ruby）で動作する、本格的な **Emacs キーバインド & Keymap 概念** を備えた自己拡張型テキストエディタです。

---

## 🌟 特徴

1. **階層型 Keymap（キーマップ）システム**:
   - `C-x C-s` や `C-x C-c` などのプレフィックスキーを階層型キーマップとして管理。
   - `C-x` を押すとステータスバーに `C-x-` と表示され、次のキー入力を待ちます。
   - `define_key("C-x C-s") { save }` のように、人間が読めるEmacs記法で自由にキーバインドを定義できます。
2. **`M-:` (eval-expression) & `M-!` (shell-command)**:
   - **`M-:`**（Alt + `:` または Esc → `:`）: ミニバッファで **Ruby 式** を即時評価（`lines.map!(&:upcase)`、`lines.reverse!` 等）。
   - **`M-!`**（Alt + `!` または Esc → `!`）: ミニバッファで **任意のシェルコマンド** を実行（`date`, `ls -la`, `git diff`, `ruby -v` 等）。
     - 出力が1行ならステータスバーにコンパクト表示
     - 複数行なら Emacs の `*Shell Command Output*` のように全画面表示し、`q` や `RET` でエディタに復帰！
3. **DSRプローブによる EAW（東アジア曖昧幅）自動検知**:
   - 起動時に `\e[6n` で端末の描画幅を自動測定し、記号やギリシャ文字のカーソルズレを完全防止。
4. **暗黙的な `init.rb` の自動読み込み**:
   - 起動時にトップレベルの `init.rb`（または `~/.inzm.rb`）を評価し、独自コマンドやキーバインドを注入できます。

## 📂 ディレクトリ構成

```text
examples/ruby/
├── bin/
│   └── inzm            # 実行可能スクリプト
├── lib/
│   └── inzm.rb         # エディタ本体 (Inzm::Keymap, Inzm::Editor)
├── init.rb             # トップレベル設定ファイル（ユーザー拡張DSL）
├── sample.txt          # テスト用テキスト
└── README.md
```

---

## 🚀 動かし方

```bash
cd examples/ruby
./bin/inzm sample.txt
```

## ⌨️ Emacs キーバインド一覧

### 移動
| キー | 動作 |
| :--- | :--- |
| **C-p** / **C-n** | 前の行 / 次の行（↑ / ↓） |
| **C-b** / **C-f** | 前の文字 / 次の文字（← / →） |
| **C-a** / **C-e** | 行頭へ / 行末へ |
| **M-v** / **C-v** | 1画面上へスクロール / 1画面下へスクロール |
| **矢印キー** | 端末標準の矢印キーでも移動可能 |

### 編集
| キー | 動作 |
| :--- | :--- |
| **Backspace** | 直前の文字を削除（行頭なら行結合） |
| **C-d** | 直後の文字を削除（Deleteキー相当） |
| **C-k** | 行末まで削除（kill-line） |
| **C-g** | プレフィックスキー入力やプロンプトのキャンセル (quit) |

### ファイル & システム
| キー | 動作 |
| :--- | :--- |
| **C-x C-s** (または C-s) | ファイル保存（末尾 `\n` 保証） |
| **C-x C-c** (または C-q) | エディタ終了 |

### 自己拡張 (Eval & Shell)
| キー | 動作 |
| :--- | :--- |
| **M-:** (Alt + `:` または Esc → `:`) | **`eval-expression`**（Ruby 式をミニバッファで評価） |
| **M-!** (Alt + `!` または Esc → `!`) | **`shell-command`**（任意のシェルコマンドを実行） |

### 🛠 `init.rb` で追加されている拡張キー
| キー | 動作 |
| :--- | :--- |
| **M-u** (Alt + u) | 現在行をすべて大文字に変換 |
| **C-x d** | 現在行をすぐ下に複製 |
| **C-x k** | バッファを全消去して新規状態にする |
