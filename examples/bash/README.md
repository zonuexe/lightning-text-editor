# inzm.sh - Bash (ed/ex風 ラインエディタ) 実装サンプル

全画面TUI（代替画面バッファや生モード）をあえて使わず、Unix最初期から続く **ed / ex スタイルのラインエディタ（Line Editor）** をBashスクリプト1本で実装したサンプルです。

内部エンジンとして **sed / awk / grep / wc** などの伝統的なUnixツールスタックを直接活用し、入力インターフェースには **GNU Readline / Editline（`read -e` + `history -s`）** をフル統合しています。

---

## 🌟 特徴

1. **代替スクリーン不使用（No Alternate Screen）**:
   - 画面クリアを行わず、通常のシェルプロンプトのようにターミナルログが下に流れていくテレタイプ端末スタイル。
   - Raw Modeを使わないため、ターミナルが壊れる心配が一切ありません。
2. **GNU Readline / Editline フル対応**:
   - `read -e` により、コマンド入力時に **`Ctrl+A`（行頭）、`Ctrl+E`（行末）、`Ctrl+K`（行キル）、`Alt+B` / `Alt+F`（単語移動）** などの強力なEmacsキーバインドが使用可能。
   - `history -s` により、**上/下矢印キーで過去に入力したコマンド履歴を呼び出せる** ほか、**`Ctrl+R` でのインクリメンタル履歴検索** も動作します。
3. **Unixスタック連携**:
   - 置換コマンド（`s/old/new/g`）は `sed` を呼び出し。
   - 行番号付き表示（`n`）は `awk` を呼び出し。
   - 正規表現検索（`/pattern/`）は `grep -n` を呼び出し。

---

## 🚀 起動方法

```bash
cd examples/bash
./inzm.sh sample.txt
```
（起動時に読み込んだファイルのバイト数が表示されます）

## ⌨️ ed コマンドリファレンス

プロンプト `* ` に対してコマンドを入力します。

### 表示・移動
| コマンド | 動作 | 例 |
| :--- | :--- | :--- |
| **`p`** | カレント行を表示 | `p` (カレント行), `3p` (3行目), `1,$p` または `,p` (全行表示) |
| **`n`** | 行番号付きで表示 (number) | `,n` (全行を行番号付きで表示) |
| **`数字`** | 指定行へジャンプして表示 | `1` (先頭行へ), `$` (最終行へ), `5` (5行目へ) |
| **Enter (空行)** | 次の行へ進んで表示 | Enterを連打するだけで1行ずつ読み進められる |
| **`/pattern/`** | 正規表現で下方向検索してジャンプ | `/Unix/` |

### 編集・追記
| コマンド | 動作 | 例 |
| :--- | :--- | :--- |
| **`a`** | カレント行の直下にテキストを追記 (append)。**単独の `.` で終了** | `3a` (3行目の下に入力開始) |
| **`i`** | カレント行の直前にテキストを挿入 (insert)。**単独の `.` で終了** | `1i` (先頭に挿入) |
| **`d`** | 行を削除 (delete) | `d` (カレント行削除), `2,4d` (2〜4行目を削除) |
| **`s/old/new/g`** | sed正規表現による文字列置換 | `s/typo/feature/g`, `,s/foo/bar/g` (全行置換) |

### ファイル & システム
| コマンド | 動作 | 例 |
| :--- | :--- | :--- |
| **`w [file]`** | 保存 (write)。書き込んだバイト数を表示 | `w`, `w backup.txt` |
| **`q`** | 終了 (quit)。未保存の変更がある場合は `?` で警告 | |
| **`q!`** | 変更を破棄して強制終了 | |
| **`h`** | 直前の `?` エラーの詳細理由を表示 (help) | エラーが出たときに `h` を押すと理由がわかる |
| **`P`** | プロンプト（`* `）の表示/非表示をトグル | |
