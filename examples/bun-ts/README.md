# inzm - Bun + TypeScript 実装サンプル (Shiki ハイライト搭載)

Bun と TypeScript を使った、フルスクリーン対応・スクロール・全角文字・QuickRun、そして **[Shiki](https://shiki.style/) による VS Code 品質シンタックスハイライト** を備えたテキストエディタです。

---

## 🌟 特徴

1. **Shiki による本格シンタックスハイライト**:
   - VS Code と同じ TextMate 文法エンジンを使用。
   - 美しい **Nord テーマ** でターミナル上に 24-bit TrueColor でコードを着色。
   - 拡張子（`.ts`, `.js`, `.py`, `.rb`, `.php`, `.rs`, `.go`, `.json`, `.md` 等）から言語を自動判別。
2. **DSRプローブによる EAW（東アジア曖昧幅）自動検知**:
   - 起動時に `\x1b[6n` で端末の曖昧文字（`α` など）の描画幅を自動測定。
   - 端末の設定に応じて `※`, `★`, `α`, `℃` などの記号幅を動的に切り替え、カーソルのズレを完全撲滅！
3. **ハイライトキャッシュ & ゼロ遅延スクロール**:
   - テキスト編集時のみ差分トークナイズを行い、カーソル移動やスクロール時はキャッシュを描画するため、超高速レスポンスを維持。
3. **QuickRun (`Ctrl+R`)**:
   - 編集中のファイルを保存し、タイムアウト付きで排他実行。`q` でエディタに復帰。

---

## 🚀 セットアップ & 起動

```bash
cd examples/bun-ts
bun install   # shiki のインストール (初回のみ)
bun run inzm.ts inzm.ts
```

---

## ⌨️ キーバインド

| キー | 動作 |
| :--- | :--- |
| **矢印キー (↑ ↓ ← →)** | カーソル移動（全角対応、行末クランプ、行跨ぎ） |
| **Home** | 行頭へジャンプ (`Fn + Left`) |
| **End** | 行末へジャンプ (`Fn + Right`) |
| **PageUp / PageDown** | 1画面分ジャンプ (`Fn + Up` / `Fn + Down`) |
| **文字入力** | カーソル位置に文字挿入（Shikiがリアルタイム再ハイライト） |
| **Enter** | 改行 |
| **Backspace** | 1文字削除 / 行頭の場合は行結合 |
| **Ctrl+S** | ファイル保存（末尾 `\n` 保証） |
| **Ctrl+R** | **QuickRun**（保存してタイムアウト付きで排他実行、`q` で復帰） |
| **Ctrl+Q** | 終了 |
