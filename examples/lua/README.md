# inzm.lua - Lua (micro 風モダンPC操作 & フルLua実装) 実装サンプル

オリジナルは Go 言語で書かれ Lua で拡張可能な人気モダンエディタ **[micro](https://micro-editor.github.io/)** を、**あえて 100% ピュアな Lua のみで実装したオマージュエディタ** です。外部依存ゼロ（Lua 5.3+ 標準のみ）で動作します。

---

## 🌟 特徴

1. **micro 伝統の画面レイアウト**:
   - **Row 1 .. Rows - 2**: 行番号付きテキスト編集エリア（縦スクロール追従、チルダ `~` 表示）。
   - **Row Rows - 1**: 反転ステータスライン（ファイル名、変更状態、行・列・パーセンテージ、EAW状態）。
   - **Row Rows**: **micro 最大の特徴である最下部コマンドプロンプト (`> `)**。
2. **現代的な PC キーバインド**:
   - `Ctrl+S`（保存）、`Ctrl+Q`（終了・未保存ガード付き）、`Ctrl+D`（行複製）、`Ctrl+K`（行カット）、`Ctrl+U`（ペースト）。
3. **micro のコマンドバー (`Ctrl+E`)**:
   - `Ctrl+E` を押すと最下行に `> ` プロンプトが出現し、micro 風のコマンドを実行可能：
     - `> save [file]` (保存)
     - `> quit` (終了)
     - `> run <cmd>` (外部シェルコマンドを排他画面で実行)
     - `> eval <code>` (Luaコードをその場で即時実行)
     - `> upper` (init.lua で定義した全大文字化コマンド！)
     - `> count` (init.lua で定義した単語数・行数カウント！)
4. **🖱 マウスサポート完全対応 (micro名物！)**:
   - SGR 1006 拡張マウスプロトコルに対応。
   - **テキスト上をクリックすると、その位置へカーソルがピッとジャンプ！**
   - **マウスホイールを回転させると、画面がスイスイ上下スクロール！**
   - コマンドプロンプトで `set mouse off` / `set mouse on` とトグル可能。
5. **フル Lua によるプラグイン拡張システム (`init.lua`)**:
   - 起動時に `./init.lua`（または `~/.config/micro/init.lua`）を自動実行。
   - `micro.addCommand(name, fn)` でユーザー独自コマンドを追加可能。
   - `micro.on("onSave", fn)` などのイベントフックを登録可能。
6. **DSRプローブによる EAW 自動検知 & 代替画面バッファ**:
   - 起動時に `\27[6n` で端末の描画幅を測定し、日本語や特殊記号のズレを防止。
   - 代替画面バッファにより、終了時にシェル履歴を一切汚しません。

## 🚀 起動方法

```bash
cd examples/lua
./inzm.lua sample.txt
```
または
```bash
lua inzm.lua sample.txt
```

## ⌨️ キーバインド & コマンド

### 1. キーショートカット & マウス
| キー / 操作 | 動作 |
| :--- | :--- |
| **左クリック** | **クリックした位置へカーソルジャンプ！** |
| **マウスホイール** | **上下スクロール！** |
| **Ctrl+S** | ファイル保存（末尾 `\n` 保証） |
| **Ctrl+Q** | 終了（未保存時は警告メッセージを表示） |
| **Ctrl+E** | **コマンドプロンプト (`> `) を開く** |
| **Ctrl+F** | 検索プロンプト (`> find `) を開く |
| **Ctrl+D** | **現在行を下に複製 (Duplicate)** |
| **Ctrl+K** | **行カット (Cut line)** |
| **Ctrl+U** | **カットした行を貼り付け (Paste line)** |
| **矢印キー** | カーソル移動（全角・日本語対応、行跨ぎ） |
| **Home / End** | 行頭 / 行末 へジャンプ |
| **PageUp / PageDown** | 1画面分ジャンプ |

---

### 2. コマンドプロンプト (`Ctrl+E` 入力時)

| コマンド | 動作 |
| :--- | :--- |
| **`save [file]`** | バッファを保存 |
| **`quit`** | エディタ終了 (`quit!` で強制終了) |
| **`run <cmd>`** | 任意のシェルコマンドを排他画面で実行して `q` で復帰 |
| **`eval <code>`** | 任意の Lua 式を評価して結果を表示 |
| **`set mouse on/off`** | マウス操作の有効化 / 無効化をトグル |
| **`upper`** | **`init.lua` で定義された独自コマンド（全行大文字化！）** |
| **`count`** | **`init.lua` で定義された独自コマンド（行数・単語数カウント）** |
