# inzm - PHP (ZONU inzm: nano風レイアウト & 操作体系) 実装サンプル

Composer不要・外部ライブラリ一切なし！
伝統的な **GNU nano（ZONU inzm）** の画面レイアウト（タイトルバー、ステータスライン、最下部2行ショートカットバー）と操作体系を忠実に再現した、単一ファイルのPHP製ターミナルエディタです。

---

## 🌟 特徴

1. **ZONU inzm 伝統の画面レイアウト**:
   - **Row 1 (タイトルバー)**: 反転表示で `ZONU inzm 1.0`、ファイル名、変更状態（`Modified`）、EAW検知結果を表示。
   - **Row 2 .. Rows - 3**: 行番号付きテキスト編集エリア（縦スクロール追従、チルダ表示）。
   - **Row Rows - 2 (ステータスライン)**: `[ Wrote N lines ]` などの通知メッセージやプロンプト表示。
   - **Row Rows - 1 .. Rows (ショートカットバー)**: nano 最大の代名詞である **最下部2行の `^X` ショートカットガイド**（キーシンボル反転表示）。
2. **DSRプローブによる EAW（東アジア曖昧幅）自動検知**:
   - 起動時に `\x1b[6n` で端末の曖昧文字（`α` など）の描画幅を瞬時に測定。
   - EAW環境なら `mb_strwidth` をフル活用し、非EAW環境なら安全な文字幅補正へ自動適応。
3. **nano 操作体系**:
   - **`^X` (`Ctrl+X`)**: 終了（未保存時は保存確認プロンプトが出現）。
   - **`^O` (`Ctrl+O`)**: WriteOut（保存）。ファイル名確認プロンプト付き。
   - **`^K` / `^U`**: 行カット / ペースト（Uncut）。
   - **`^T` (`Ctrl+T`)**: Execute（編集中のPHPコードを即時実行）。
   - **`^W` (`Ctrl+W`)**: Where Is（単語検索）。
   - **`^C` (`Ctrl+C`)**: Location（行・列・パーセンテージの現在位置表示）。
4. **代替画面バッファ (Alternate Screen)**:
   - 終了時にシェル履歴を一切汚さず、起動直前の画面へ復帰。

---

## 🚀 起動方法

```bash
cd examples/php
./inzm.php sample.php
```
または
```bash
php inzm.php sample.php
```

## ⌨️ nano ショートカット一覧

### nano コマンド (`Ctrl` = `^`)
| キー | コマンド名 | 動作 |
| :--- | :--- | :--- |
| **^X** (`Ctrl+X`) | **Exit** | エディタ終了（未保存時は `Save modified buffer?` で確認） |
| **^O** (`Ctrl+O`) | **WriteOut** | ファイル保存（`File Name to Write:` プロンプト付き） |
| **^K** (`Ctrl+K`) | **Cut Text** | 現在行をカットしてカットバッファへ格納 |
| **^U** (`Ctrl+U`) | **Paste Text** | カットした行を現在行の下に貼り付け（Uncut） |
| **^T** (`Ctrl+T`) | **Execute** | 編集中のPHPスクリプトを即時実行（`q` でエディタに復帰） |
| **^W** (`Ctrl+W`) | **Where Is** | 単語検索（マッチした位置へカーソルジャンプ） |
| **^C** (`Ctrl+C`) | **Location** | 現在行・総行数・列・パーセンテージを表示 |
| **^G** (`Ctrl+G`) | **Get Help** | ヘルプ概要をステータスバーに表示 |

### 移動・ナビゲーション
| キー | 動作 |
| :--- | :--- |
| **矢印キー (↑ ↓ ← →)** | カーソル移動（全角対応、行末クランプ、行跨ぎ） |
| **^A** (`Ctrl+A`) / **Home** | 行頭へジャンプ |
| **^E** (`Ctrl+E`) / **End** | 行末へジャンプ |
| **^Y** (`Ctrl+Y`) / **PageUp** | 1画面分上へスクロール (Prev Page) |
| **^V** (`Ctrl+V`) / **PageDown** | 1画面分下へスクロール (Next Page) |
| **Enter / Backspace** | 改行 / 1文字削除（行結合対応） |
