# inzm - PHP (単一ファイル・ミニマル) 実装サンプル

Composer不要・外部ライブラリ一切なし！PHP標準機能（`mb_strwidth`）のみで実装された、約200行の超コンパクトなターミナルテキストエディタです。

---

## 🌟 特徴

1. **Composer不要・単一ファイル**:
   - `inzm.php` 1ファイルだけで即座に起動可能。
2. **`mb_strwidth` による完璧な全角・日本語対応**:
   - PHP標準のマルチバイト関数を活用し、ひらがな・漢字の表示幅を1行で完璧に計算。
3. **QuickRun (`Ctrl+R`)**:
   - 編集中のPHPコードをその場で実行し、実行結果を排他画面でプレビュー。`q` でエディタに復帰。
4. **代替画面バッファ (Alternate Screen)**:
   - 終了時にシェル履歴を一切汚さず、起動前の画面を元通り復元。

---

## 🚀 起動方法

```bash
cd examples/php
./inzm.php sample.php
```
または
```bash
php inzm.php sample.php
```

---

## ⌨️ キーバインド

| キー | 動作 |
| :--- | :--- |
| **矢印キー (↑ ↓ ← →)** | カーソル移動（全角対応、行末クランプ、行跨ぎ） |
| **Home / End** | 行頭 / 行末 へジャンプ |
| **PageUp / PageDown** | 1画面分ジャンプ |
| **文字入力** | カーソル位置に文字挿入（日本語対応） |
| **Enter** | 改行 |
| **Backspace** | 1文字削除 / 行頭の場合は行結合 |
| **Ctrl+S** | ファイル保存（末尾 `\n` 保証） |
| **Ctrl+R** | **QuickRun**（保存して `php <file>` を即時実行、`q` で復帰） |
| **Ctrl+Q / Ctrl+C** | 終了 |
