# inzm - Go (Vim モーダル編集 & マルチバッファ) 実装サンプル

Go言語で実装された、単一実行バイナリとして動作する **Vim風モーダル編集 & タブ式マルチバッファエディタ** です。

---

## 🌟 特徴

1. **型安全な Vim モーダル編集**:
   - **NORMAL モード**: `h/j/k/l` 移動、`0/$`、`x`（文字削除）、`dd`（行削除）、`i/a/A/o/O`（インサート移行）。
   - **INSERT モード**: タイピング、Backspace、Enter、全角文字対応。`Esc` でノーマル復帰。
   - **COMMAND モード**: 最下行で `:w`（保存）、`:q`（終了）、`:wq`、`:q!`。
2. **構造体による独立マルチバッファ管理**:
   - 各バッファ（ファイル）ごとに **カーソル座標、スクロール位置、未保存フラグ** を完全に独立して保持。
   - 画面最上部に **Vim風のタブバー**（`[1: sample1.txt]  2: sample2.txt*`）を常時表示。
   - コマンドライン操作（`:e`, `:bn`, `:bp`, `:bd`）だけでなく、**`Ctrl+N` / `Ctrl+P`** で爆速切替が可能！
3. **Goならではの単一バイナリ**:
   - `go build` でどこでも動くポータブルな単一バイナリが生成可能。

---

## 🚀 ビルド & 起動

複数ファイルを引数に渡して起動できます：

```bash
cd examples/go
go build -o inzm main.go

# 2つのバッファを同時に開いて起動！
./inzm sample1.txt sample2.txt
```

## ⌨️ キーバインド & コマンド

### 1. ノーマルモード (NORMAL)
| キー | 動作 |
| :--- | :--- |
| **h / j / k / l** | 左 / 下 / 上 / 右 移動（矢印キーでも可） |
| **0 / $** | 行頭 / 行末 へ移動 |
| **i / a / A** | カーソル位置 / 右隣 / 行末 で挿入モードへ |
| **o / O** | 現在行の下 / 上 に新しい行を作って挿入モードへ |
| **x** | カーソル下の1文字を削除 |
| **dd** | 現在行を1行まるごと削除 |
| **:** | コマンドラインモードへ |
| **Ctrl+N / Ctrl+P** | **次のバッファ / 前のバッファへ切り替え！** |
| **] / [** | 次 / 前のバッファへ切り替え |

### 2. インサートモード (INSERT)
| キー | 動作 |
| :--- | :--- |
| **文字入力** | カーソル位置に文字挿入（日本語・全角幅対応） |
| **Enter / Backspace** | 改行 / 文字削除（行結合対応） |
| **Esc / Ctrl+[** | **ノーマルモードへ復帰** |

### 3. コマンドラインモード (COMMAND: `:` 入力時)
| コマンド | 動作 |
| :--- | :--- |
| **:w** | 現在のバッファを保存（末尾 `\n` 保証） |
| **:q** | 終了（未保存時はエラーで保護） |
| **:q!** | 変更を破棄して強制終了 |
| **:wq** | 保存して終了 |
| **:e <ファイル名>** | 新しいファイルをバッファに開く |
| **:bn / :bp** | 次のバッファ / 前のバッファへ切替 |
| **:bd / :bd!** | 現在のバッファを閉じる |
| **:ls** | 開いているバッファ一覧を表示 |
