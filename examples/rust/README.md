# inzm - Rust (MinEd風 Unicodeファーストクラス) 実装サンプル

世界で初めてターミナルで本格的に UTF-8 / Unicode をサポートした伝説のエディタ **[MinEd (Mined)](https://mined.github.io/)** にインスパイアされた、Unicode・書記素クラスタ（Grapheme Cluster）完全対応のRust製テキストエディタです。

---

## 🌟 特徴

1. **カーソル下の Unicode 情報リアルタイム解析（MinEd名物！）**:
   - カーソルが乗っている文字の **Unicode コードポイント（`U+3042` 等）** と **端末セル幅（`Wide: 2 cells` 等）** をステータスバーに常時表示。
   - 複数コードポイントで構成される結合文字（`か゚`）や絵文字（`👨‍👩‍👧‍👦`）の内部構造が手に取るように分かります。
2. **書記素クラスタ（Grapheme Cluster）完全対応**:
   - `unicode-segmentation` クレートにより、家族絵文字（`👨‍👩‍👧‍👦`）や国旗（`🇯🇵`）、結合文字を 1 つの不可分な「1書記素」として扱います。
   - Backspace で消しても文字化けや濁点残りが発生せず、安全に編集可能。
3. **Unicode Hex 入力機能 (`Ctrl+U`)**:
   - `Ctrl+U` を押してコードポイント（例: `3042` や `1F363`）を入力すると、対応する Unicode 文字（`あ` や `🍣`）を直接バッファに挿入できます。
4. **型安全・ゼロコスト抽象化の TUI**:
   - `crossterm` による高速な画面描画、代替画面バッファ、RAIIガードによる安全なターミナル復元。

---

## 🚀 ビルド & 起動

```bash
cd examples/rust
cargo run -- sample.txt
```

---

## ⌨️ キーバインド

| キー | 動作 |
| :--- | :--- |
| **矢印キー (↑ ↓ ← →)** | カーソル移動（**カーソル下の Unicode コードポイントがリアルタイム更新！**） |
| **Home / End** | 行頭 / 行末 へジャンプ |
| **PageUp / PageDown** | 1画面分ジャンプ |
| **文字入力** | カーソル位置に文字挿入 |
| **Enter** | 改行 |
| **Backspace** | **書記素単位で削除**（結合文字や絵文字が絶対に壊れません） |
| **Ctrl+U** | **Unicode Hex Input**（コードポイントを直接打って文字挿入！） |
| **Ctrl+S** | ファイル保存（末尾 `\n` 保証） |
| **Ctrl+Q / Ctrl+C** | 終了 |
