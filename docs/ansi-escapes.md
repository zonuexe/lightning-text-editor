# ANSIエスケープシーケンス・チートシート

エディタ開発では、ターミナルに対して「画面を消せ」「カーソルを(x, y)へ移動せよ」「色を変えろ」という指示を**ANSIエスケープシーケンス**と呼ばれる特殊な文字列を出力することで伝えます。

すべてのシーケンスは `ESC`（ASCIIコード 27、16進数で `\x1b`）から始まります。

---

## 📍 カーソル制御

| シーケンス | 動作 | 例 / 備考 |
| :--- | :--- | :--- |
| `\x1b[H` | カーソルを左上（1行目, 1列目）に移動 | 再描画の開始時に多用 |
| `\x1b[{row};{col}H` | カーソルを指定した行と列に移動 (1-indexed) | 例: `\x1b[5;10H` (5行目10列目) |
| `\x1b[A` | カーソルを1行上へ | |
| `\x1b[B` | カーソルを1行下へ | |
| `\x1b[C` | カーソルを1列右へ | |
| `\x1b[D` | カーソルを1列左へ | |
| `\x1b[?25l` | **カーソルを非表示** | 再描画中のチラつき防止に必須 |
| `\x1b[?25h` | **カーソルを表示** | 描画完了後や終了時に必ず呼ぶ |

---

## 🧹 画面・行のクリア

| シーケンス | 動作 | 備考 |
| :--- | :--- | :--- |
| `\x1b[2J` | **画面全体をクリア** | 起動時や終了時に使用 |
| `\x1b[K` | **カーソル位置から行末までクリア** | 行を描画した後に呼ぶとゴミが残らない |
| `\x1b[2K` | 行全体をクリア | |

---

## 🎨 スタイル・色付け

`\x1b[{コード}m` の形式で文字の装飾や色を指定します。`\x1b[0m` でリセットします。

| コード | 意味 | 用途 |
| :--- | :--- | :--- |
| `\x1b[0m` | **全リセット（通常表示）** | 装飾の解除 |
| `\x1b[1m` | 太字 (Bold) | 強調表示 |
| `\x1b[7m` | **反転表示 (Invert / Reverse)** | ステータスバーや選択範囲に最適 |
| `\x1b[30m` 〜 `\x1b[37m` | 文字色（黒, 赤, 緑, 黄, 青, マゼンタ, シアン, 白） | 構文強調・メッセージ |
| `\x1b[40m` 〜 `\x1b[47m` | 背景色（黒, 赤, 緑, 黄, 青, マゼンタ, シアン, 白） | ステータスバーの背景 |
| `\x1b[90m` | 薄いグレー（Bright Black） | 行番号の表示におすすめ |

---

## 💡 エディタ描画のゴールデンパターン

描画関数（Render）の中で毎回このパターンを実行すると、画面のチラつき（フリッカー）がなく綺麗なTUIが実現できます。

```typescript
function render(lines: string[], cursorX: number, cursorY: number) {
  let output = "";

  output += "\x1b[?25l"; // 1. カーソル隠す
  output += "\x1b[H";     // 2. 左上へ移動

  // 3. テキスト行の描画
  for (let i = 0; i < lines.length; i++) {
    output += `\x1b[90m${(i + 1).toString().padStart(3, " ")} \x1b[0m`; // 行番号
    output += lines[i];
    output += "\x1b[K\r\n"; // 行末まで消して改行
  }

  // 4. ステータスバーの描画
  output += "\x1b[7m -- キミのエディタ (Ctrl+Q: 終了, Ctrl+S: 保存) -- \x1b[0m\x1b[K";

  // 5. カーソル位置を元の場所へ（行番号の幅 + 4列オフセット考慮）
  output += `\x1b[${cursorY + 1};${cursorX + 5}H`;
  output += "\x1b[?25h"; // 6. カーソル再表示

  process.stdout.write(output);
}
```
