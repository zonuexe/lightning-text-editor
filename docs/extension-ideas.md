# 40分完了後の拡張アイデア集（デザートメニュー）

エディタの基本機能（MVP）が40分以内に完成して時間が余ったときや、さらなる改造に挑戦したいときの「+5〜15分で足せる実用機能」のレシピ集です。

---

## 🛠 1. 開発支援系（QuickRunの発展）

### 1-1. ワンキー・フォーマッター (`Ctrl+L` / コマンド実行) 【所要時間: 5〜8分】
- **内容**: `biome format`、`prettier`、`ruff`、`rubocop` などのLinter/Formatterをバックグラウンド実行し、現在開いているバッファをその場で整形。
- **ポイント**: プロセスにテキストを標準入力で渡すか、一時保存してフォーマッターを実行後にバッファを再読み込み。

### 1-2. Git Diff ビューア (`:diff` / `Ctrl+Shift+D`) 【所要時間: 5分】
- **内容**: 画面を排他的にクリアして `git diff --color` を実行し、今編集中のファイルの変更差分をカラー表示。`q` でエディタに復帰。
- **ポイント**: QuickRun のロジック（`currentMode = 'DIFF_VIEW'`）をそのまま流用可能。外部ページャや対話コマンドを起動するタイプにする場合は、実行前に一度 Raw Mode / 代替画面を解除（`leave`）し、終了後に再有効化（`enter`）します（`docs/raw-mode.md` 参照）。

### 1-3. テストランナー (`Ctrl+T`) 【所要時間: 5分】
- **内容**: `bun test`、`pytest`、`rspec` などのテストスイートを排他実行し、結果を閲覧して `q` で復帰。

## ✂️ 2. 編集・操作系

### 2-1. 行キル & 行複製 (`Ctrl+K` / `Ctrl+D`) 【所要時間: 5分】
- **行キル (`Ctrl+K`)**:
  - `lines.splice(cursorY, 1)` で現在行を即座に削除。行がなくなったら `lines = [""]`。
- **行複製 (`Ctrl+D`)**:
  - `lines.splice(cursorY + 1, 0, lines[cursorY])` で現在行をすぐ下へ丸ごと複製。

### 2-2. 指定行ジャンプ (`Ctrl+G`) 【所要時間: 8分】
- **内容**: 最下部に `Jump to line: ` のプロンプトを出し、数字を入力してEnterを押すと指定行へカーソルがジャンプ。

### 2-3. インクリメンタル単語検索 (`Ctrl+F`) 【所要時間: 10〜15分】
- **内容**: 最下部に `Search: ` を表示し、文字を打ち込むたびに現在位置以降でマッチする行・列を検索してカーソルを移動。

### 2-4. マウス操作サポート（クリック移動＆ホイールスクロール） 【所要時間: 10分】
- **内容**: SGR拡張マウスプロトコル（`\x1b[?1000h\x1b[?1006h`、ドラッグも取るなら `\x1b[?1002h\x1b[?1006h`）を有効化し、クリックした画面位置（col, row）へカーソルをジャンプさせ、マウスホイールで画面をスクロールさせる。
- **ポイント**:
  - 終了時に必ず `\x1b[?1000l\x1b[?1006l`（または `\x1b[?1002l\x1b[?1006l`）で解除する。ターミナルアプリなのにマウスが動く感動は非常に大きい。
  - **ホイールはカーソル移動ではなく「画面表示（`row_offset`）のスクロール」にする**: ホイール操作で `cursor_y` まで引っ張ると元の編集位置を見失いやすいため、ホイール時は `row_offset` のみ動かしてカーソルが画面外に出たら `\x1b[?25l` で隠し、キー入力時に元のカーソル位置へ復帰させる（`render()` 内で無条件に `ensure_cursor_visible()` を呼ばない設計が鍵）。
  - ブラウザの `xterm.js` と組み合わせて使う場合も、この SGR プロトコルがそのまま動く（`xterm.js` 側の範囲選択を使いたい場合は `Shift+ドラッグ`）。

### 2-5. 範囲選択（Range Selection & コピー/カット/置換） 【所要時間: 10〜15分】
参照実装: [examples/moonbit/](../examples/moonbit/), [examples/zig/](../examples/zig/)
- **データ構造**: 現在のカーソル位置（`head`）とは別に **選択開始点（`anchor`）** を 1 つ持つ（`anchor == null` または `anchor == head` なら非選択）。描画や切り出し時は常に前後を正規化した `(start, end) = (min(anchor, head), max(anchor, head))` を使う。
- **入力と選択拡張**:
  - **キーボード**: `Shift+矢印`（`\x1b[1;2A/B/C/D`）・`Shift+Home/End`（`\x1b[1;2H/F`）・全選択時、`anchor` が未設定なら移動前のカーソル位置を `anchor` にセットしてから `head` を動かす。非 Shift の移動キーや `Esc` で `anchor` をクリア。
  - **マウスドラッグ**: SGR ボタンドラッグ追跡（`\x1b[?1002h\x1b[?1006h`）を有効にし、押下（`btn=0`）で `anchor = head = pos`、ドラッグ（`btn=32`）で `anchor` を固定したまま `head` のみ更新する。
- **選択中の編集・描画**:
  - 文字入力・`Enter`・`Tab`・ペースト時は **まず選択範囲を削除してから挿入**、Backspace / Delete 時は **選択範囲のみ削除** するだけで自然な置換挙動になる。
  - 描画時は `(start, end)` に含まれるセルを青背景等（`\x1b[44;97m`）で出力し、改行をまたぐ場合は行末に 1 マス分の反転スペースを足すと複数行選択が直感的に見える。
  - ブラウザ WASM 版では `get_selected_text()` を export しておくと、`Cmd+C` / `Cmd+X` で画面外にスクロールした長文選択もシステムクリップボードへ連携できる。

### 2-6. マルチカーソル & Undo / Redo（Piece Table 発展パターン） 【所要時間: 15〜20分】
参照実装: [examples/zig/](../examples/zig/)
- **複数カーソル**: `Selection { anchor, head }` の配列を **オフセット昇順で保持し、後ろ（大きいオフセット）から順に挿入・削除を適用** すると手前のカーソル位置がズレない。移動・編集後にソート＆重複マージを行う。
- **一括 Undo / Redo**: `PieceTable` の `Piece` 配列と `cursors[]` のスナップショットを 1 回のマルチ編集ごとに 1 つ積むことで、`Ctrl+Z` / `Ctrl+Y` で複数カーソル編集も一発で巻き戻せる。
- **副カーソル描画**: ハードウェアカーソル（`\x1b[y;xH`）はプライマリ 1 箇所のみに置き、残りのカーソル位置は別色（例: `\x1b[46;30m`）のセル反転で擬似カーソル表示する。

## 🎨 3. ビジュアル・装飾系

### 3-1. 簡易シンタックスハイライト 【所要時間: 10〜15分】
- **内容**: 描画時に正規表現で簡易的に色付けする。
  - コメント（`//.*`）→ 薄いグレー or 緑 (`\x1b[32m`)
  - 文字列（`".*?"` / `'.*?'`）→ 黄色 (`\x1b[33m`)
  - キーワード（`const|let|function|return|import|export|if|else`）→ シアン (`\x1b[36m`)
- **ポイント**: 行単位で正規表現置換（`.replace(/(pattern)/g, "\x1b[36m$1\x1b[0m")`）をかけるだけで、驚くほどコードっぽくなります。

### 3-2. カラーテーマ切り替え (`F2`) 【所要時間: 5分】
- **内容**: キー1つで「ダーク」「サイバーパンク」「モノクロ」「マトリックス」など、ステータスバーや行番号の配色セットをループ切り替え。

### 3-3. マルチバッファ管理 & タブ UI 【所要時間: 15〜20分】
参照実装: [examples/go/](../examples/go/)
- **2層の状態分離（`Editor` と `Buffer`）**:
  - テキスト本体・`cursorX / cursorY`・`rowOffset`・`filename`・`isModified` を `Buffer` 構造体へ切り出し、`Editor` 側は `buffers: Buffer[]`・`activeBuf: number`・`clipboard`・`statusMessage` だけを持つ。これによりバッファ切り替え時に各ファイルのカーソルやスクロール位置がそのまま保たれる。
- **タブバーの描画レイアウト**:
  - **Row 1**: 反転表示（`\x1b[7m`）のタブバーを描画（アクティブタブは `[1: main.go*]`、非アクティブは `2: util.go` のように区別し、画面幅を超える場合は切り詰め・スクロール）。
  - **Row 2 .. Rows - 2**: 本文エリア（タブバー 1 行が増えるため、本文表示行数は `rows - 3`、カーソル移動先も `screenY = cursorY - rowOffset + 2` になる点に注意）。
- **切り替え・開閉操作**:
  - `Ctrl+N` / `Ctrl+P`（または `:bn` / `:bp`）で次・前のバッファへ循環切り替え、`:e <file>` で既存バッファへジャンプまたは新規追加。
  - タブバー上で左クリックされた X 座標とタブ文字列の表示幅範囲を照合すれば、マウスクリックによるタブ切り替えも追加できる。
  - バッファを閉じる（`:bd`）ときは `isModified` を確認して未保存破棄を防ぎ、最後の 1 個を閉じたら空バッファを補うか終了する。

## 🛡 4. 安全・堅牢性系

### 4-1. 未保存終了ガード (Safe Quit) 【所要時間: 5分】
- **内容**: `isModified` が `true` の状態で `Ctrl+Q` を押した際、即座に終了せず「⚠️ 未保存の変更があります。もう一度 Ctrl+Q を押すと破棄して終了」とステータスバーに警告。
- **2回目の `Ctrl+Q`** で初めて `isRunning = false` とし、メインループを抜けて通常の終了クリーンアップを実行します。

### 4-2. 名前をつけて保存 (Save As) 【所要時間: 8分】
- **内容**: `untitled.txt` などの新規作成時、`Ctrl+S` を押した際に最下部でファイル名入力を受け付けて保存。

### 4-3. Bracketed Paste Mode（貼り付け保護: `\x1b[?2004h`） 【所要時間: 5分】
- **内容**: 起動時に `\x1b[?2004h` を出力し、`\x1b[200~` 〜 `\x1b[201~` の間はオートインデントや Vim のノーマルコマンド解釈を一時停止して純粋なテキスト挿入を行う。
- **ポイント**: 終了時に必ず `\x1b[?2004l` を出力して解除しないと、エディタ終了後のシェルがペースト文字を受け取れなくなるため注意。

### 4-4. ウィンドウリサイズ追従 (`SIGWINCH`) 【所要時間: 5分】
- **内容**: ターミナルの画面サイズ変更を検知して `cols` / `rows` を再取得し、`rowOffset` やビューポートを再計算して即座に再描画する。
- **ポイント**: シグナルハンドラ内で直接標準出力へ書き出すと競合・崩れの原因になるため、ハンドラでは `needsResize = true` のフラグだけを立て、メインループ先頭でサイズ再取得と描画を行う（ブロッキング `read` 中に `EINTR` が返る言語では再試行する）。
