# 40分完了後の拡張アイデア集（デザートメニュー）

エディタの基本機能（MVP）が40分以内に完成して時間が余ったときや、さらなる改造に挑戦したいときの「+5〜15分で足せる実用機能」のレシピ集です。

---

## 🛠 1. 開発支援系（QuickRunの発展）

### 1-1. ワンキー・フォーマッター (`Ctrl+F`) 【所要時間: 5〜8分】
- **内容**: `biome format`、`prettier`、`ruff`、`rubocop` などのLinter/Formatterをバックグラウンド実行し、現在開いているバッファをその場で整形。
- **ポイント**: プロセスにテキストを標準入力で渡すか、一時保存してフォーマッターを実行後にバッファを再読み込み。

### 1-2. Git Diff ビューア (`Ctrl+D`) 【所要時間: 5分】
- **内容**: 画面を排他的にクリアして `git diff --color` を実行し、今編集中のファイルの変更差分をカラー表示。`q` でエディタに復帰。
- **ポイント**: QuickRun のロジック（`currentMode = 'DIFF_VIEW'`）をそのまま流用可能。

### 1-3. テストランナー (`Ctrl+T`) 【所要時間: 5分】
- **内容**: `bun test`、`pytest`、`rspec` などのテストスイートを排他実行し、結果を閲覧して `q` で復帰。

---

## ✂️ 2. 編集・操作系

### 2-1. 行キル & 行複製 (`Ctrl+K` / `Ctrl+D`) 【所要時間: 5分】
- **行キル (`Ctrl+K`)**:
  - `lines.splice(cursorY, 1)` で現在行を即座に削除。行がなくなったら `lines = [""]`。
- **行複製 (`Ctrl+D`)**:
  - `lines.splice(cursorY + 1, 0, lines[cursorY])` で現在行をすぐ下へ丸ごと複製。

### 2-2. 指定行ジャンプ (`Ctrl+G`) 【所要時間: 8分】
- **内容**: 最下部に `Jump to line: ` のプロンプトを出し、数字を入力してEnterを押すと指定行へカーソルがジャンプ。

### 2-3. インクリメンタル単語検索 (`Ctrl+F`) 【所要時間: 10〜15分】
- **内容**: 最下部に `Search: ` を表示し、文字を打ち込むたびに現在位置以降でマッチする行・列を検索してカーソルを移動。

---

## 🎨 3. ビジュアル・装飾系

### 3-1. 簡易シンタックスハイライト 【所要時間: 10〜15分】
- **内容**: 描画時に正規表現で簡易的に色付けする。
  - コメント（`//.*`）→ 薄いグレー or 緑 (`\x1b[32m`)
  - 文字列（`".*?"` / `'.*?'`）→ 黄色 (`\x1b[33m`)
  - キーワード（`const|let|function|return|import|export|if|else`）→ シアン (`\x1b[36m`)
- **ポイント**: 行単位で正規表現置換（`.replace(/(pattern)/g, "\x1b[36m$1\x1b[0m")`）をかけるだけで、驚くほどコードっぽくなります。

### 3-2. カラーテーマ切り替え (`F2`) 【所要時間: 5分】
- **内容**: キー1つで「ダーク」「サイバーパンク」「モノクロ」「マトリックス」など、ステータスバーや行番号の配色セットをループ切り替え。

---

## 🛡 4. 安全・堅牢性系

### 4-1. 未保存終了ガード (Safe Quit) 【所要時間: 5分】
- **内容**: `isModified` が `true` の状態で `Ctrl+Q` を押した際、即座に終了せず「⚠️ 未保存の変更があります。もう一度 Ctrl+Q を押すと破棄して終了」とステータスバーに警告。
- **2回目の `Ctrl+Q`** で初めて `process.exit(0)` を実行。

### 4-2. 名前をつけて保存 (Save As) 【所要時間: 8分】
- **内容**: `untitled.txt` などの新規作成時、`Ctrl+S` を押した際に最下部でファイル名入力を受け付けて保存。
